# Tehau DeBarthe

## Building intelligent healthcare systems.

*AI moves at the speed of trust.*

I’m Tehau. I’m interested in how people, knowledge, and intelligent systems work together. Most days that means building AI, exploring new ideas, and trying to leave systems a little better than I found them.

This repository contains the source for my personal portfolio: a research-oriented, human-centered space for documenting systems, questions, experiments, and lessons from my work in machine learning and enterprise technology.

## Purpose

The site brings together four parts of my work:

- **Professional path** across enterprise platforms, application analysis, DevOps, principal data engineering, and machine learning
- **Research interests** in machine learning engineering, agentic systems, knowledge systems, and trusted AI
- **Selected systems and explorations** with public evidence where available
- **Open questions** intended to encourage thoughtful discussion, useful disagreement, and new ideas

The site is not intended to present institutional policy or make unsupported claims. Personal perspectives, research questions, project evidence, and professional experience are presented as distinct forms of information.

## Research Profile

### Machine Learning Engineering

Model development, evaluation, explainability, integration, and the surrounding software needed to make machine learning useful in real workflows.

### Agentic Systems

Tool-connected workflows with clear boundaries, observable behavior, and explicit opportunities for human review.

### Knowledge Systems

Knowledge graphs, organizational memory, retrieval, and interfaces that help information become usable context.

### Trusted AI

Architecture and governance patterns that support transparent, reviewable, secure, and human-centered intelligent systems.

## Working Principles

These are personal working principles, not institutional positions.

- **Intelligence should amplify people.** Useful AI supports judgment, reduces avoidable friction, and gives people more room for meaningful work.
- **Trust is part of the architecture.** Clarity, accountability, security, and visible human control should be designed into the system from the beginning.
- **Claims should be inspectable.** Research questions, methods, limitations, and evidence should remain distinguishable from interpretation.
- **Knowledge should compound.** Good systems preserve context, connect learning over time, and make useful discoveries easier to revisit and share.

## Running Locally

### Option 1: Open the file directly

Open `index.html` in a modern browser.

### Option 2: Use a local static server

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in a browser.

### PowerShell alternative

```powershell
python -m http.server 8000
```

Stop the server with `Ctrl+C`.

## Design Direction

The portfolio is designed to balance:

- **Research rigor:** clear distinctions between questions, evidence, methods, limitations, and perspective
- **Clinical clarity:** restrained color, precise typography, readable structure, and minimal decorative noise
- **Personal voice:** curiosity, reflection, optimism, and a willingness to help
- **AI/ML identity:** intelligent systems, knowledge graphs, agentic workflows, explainability, and trusted AI

The goal is not to resemble a conventional résumé or consulting page. The site is intended to feel like a public research notebook authored by a working Machine Learning Engineer.

## Accessibility and Content Standards

When updating the site:

- Preserve semantic headings and landmarks
- Maintain sufficient color contrast
- Keep keyboard-accessible navigation and controls
- Respect reduced-motion preferences
- Avoid unsupported metrics and promotional superlatives
- Label personal beliefs and open questions clearly
- Link to public evidence where a project or method is referenced
- Protect confidential, proprietary, and organizational information
